Capture with Siri

Say "Hey Siri, Offload this" and speak. What you say lands in your feed the next time Offload opens.

Set up the shortcut on iPhone

  1. Open the Shortcuts app, tap +, and name the shortcut Offload this. Siri uses the name as the phrase.
  2. Add the action Dictate Text.
  3. Add Get Contents of URL and paste this address:
  4. In that action, tap Show More. Set Method to POST. Add a header named Authorization with this value:
  5. Set Request Body to JSON, add a Text field named text, and set its value to the Dictated Text variable.
  6. Add Show Result so Siri says "Saved to Offload."

Things you can say

  • "Podcast idea: interview a barista, category work"Note filed under Work
  • "Remind me to call Mom tomorrow at 6 PM"Reminder for tomorrow, 6:00 PM
  • "Remind me every Monday at 9 to send the report"Repeating reminder
  • "Grocery list milk, eggs and bread"New checklist with three items
  • "Add coffee to my grocery list"Adds an item to that list

On Android, the free HTTP Shortcuts app can send the same request from a home-screen or Assistant shortcut.
